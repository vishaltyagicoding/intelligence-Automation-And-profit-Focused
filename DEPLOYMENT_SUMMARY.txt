AFTER (FIXED):

═══════════════════════════════════════════════════════════════════════════════
HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════

1. PERSISTENT STORAGE:
   - Added persistentSignalsRef to store signals across timeframe changes
   - Key format: "BTCUSD:5m:1234567890" → SeriesMarker
   - Signals stored FOREVER (never deleted)

2. STABLE POSITION:
   - Signal position calculated from database timestamp
   - Rounded to exact candle start: Math.floor(timestamp / interval) * interval
   - Same timestamp = same candle = same position FOREVER

3. TIMEFRAME SWITCH:
   - Restore signals from persistent storage for current asset+timeframe
   - Apply signals immediately (before new data loads)
   - Merge new signals with existing signals (no replacement)
