PART 1: SETUP (5 Minutes)
═══════════════════════════════════════════════════════════════

□ Step 1: Open Kaggle
  → Go to: https://www.kaggle.com/code
  → Click: "New Notebook" button

□ Step 2: Copy Training Code
  → Open: kaggle_training_notebook.py
  → Select: ALL code (Ctrl+A)
  → Copy: Ctrl+C
  → Paste: Into Kaggle (Ctrl+V)

□ Step 3: Enable GPU
  → Click: "Settings" (right sidebar)
  → Find: "Accelerator"
  → Select: "GPU" (NOT "None" or "TPU")
  → Click: "Save"

□ Step 4: Start Training
  → Click: "Run All" button
  → Verify: "CUDA available: True" appears
  → Verify: "GPU: Tesla P100" appears

□ Step 5: Wait
  → Time: 2-4 hours
  → Status: Check progress in output
  → Coffee: ☕ Take a break!

═══════════════════════════════════════════════════════════════

PART 2: AFTER TRAINING (5 Minutes)
═══════════════════════════════════════════════════════════════

□ Step 1: Download Model
  → Click: "Output" tab (right sidebar)
  → Find: "best_model.pth" file
  → Click: Download icon
  → Verify: File in Downloads folder (~50 MB)

□ Step 2: Copy to Project
  Windows:
  → Open: Command Prompt
  → Run: mkdir models\production
  → Run: copy "%USERPROFILE%\Downloads\best_model.pth" "models\production\model.pth"
  
  Linux/Mac:
  → Open: Terminal
  → Run: mkdir -p models/production
  → Run: cp ~/Downloads/best_model.pth models/production/model.pth

□ Step 3: Load Model
  → Run: python manage.py load_model --checkpoint models/production/model.pth
  → Verify: "✅ Model loaded successfully!" appears
  → Verify: Accuracy shown (e.g., "72.45%")

□ Step 4: Restart Services
  Docker:
  → Run: docker-compose restart django celery_worker
  → Verify: Services restarted
  
  Manual:
  → Stop: Django and Celery (Ctrl+C)
  → Start: python manage.py runserver
  → Start: celery -A neuraltrade worker -l info

□ Step 5: Test AI
  → Run: curl -X POST http://localhost:8000/api/ai/analyze/ -H "Content-Type: application/json" -d '{"symbol":"BTCUSDT","market":"CRYPTO"}'
  → Verify: Response with "decision", "confidence"
  → Verify: No errors

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: Out of Memory
□ Solution: Change batch_size=32 to batch_size=16

Problem: Training too slow
□ Solution: Verify GPU enabled (Settings → Accelerator → GPU)

Problem: Can't download model
□ Solution: Wait for training to reach 100%

Problem: Model file not found
□ Solution: Create directory first: mkdir -p models/production

Problem: AI not responding
□ Solution: Check logs: docker-compose logs django
