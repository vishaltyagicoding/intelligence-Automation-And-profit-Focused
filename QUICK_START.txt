================================================================================
TROUBLESHOOTING
================================================================================

Issue: SSH Permission Denied
Fix: Run in PowerShell as Administrator
    $pemFile = "D:\...\singapore-pem-file.pem"
    icacls $pemFile /inheritance:r
    icacls $pemFile /grant:r "${env:USERNAME}:F"

Issue: SSL Certificate Failed
Fix: Wait 30 mins for DNS propagation, then re-run deployment

Issue: Services Not Starting
Fix: sudo docker-compose down
     sudo docker-compose build --no-cache
     sudo docker-compose up -d

Issue: Historical Signals Fail
Fix: Drop alternation trigger first:
     sudo docker-compose exec db psql -U smartrisk_user -d smartrisk_db \
       -c "DROP TRIGGER IF EXISTS enforce_signal_alternation ON reversal_zones CASCADE;"
